# 开发与 Git 历史说明

## 首次入库

项目此前在本地持续开发，但在 2026-10-28 整理比赛仓库时，本地 `main` 分支及远程仓库均没有 Git 提交。本次将当时实际存在的源码作为初始版本入库，不倒填提交日期，也不将整理前的各次对话或功能迭代伪造成历史提交。

从首次入库起，源码、配置、文档的后续修改通过正常 Git 提交保留。评审可用 `git log --stat` 查看实际提交时间、作者和文件差异。

## 本地开发内容概览

以下是现有实现的工作范围说明，不代替 Git 历史：

- 工作台、文件与自然语言导入、分类与日期汇总、基础图表。
- MiMo Agent、连续指令、工具执行反馈、多值筛选和原始明细联动。
- 账号认证、独立分析记录、保存与删除恢复。
- 语音转文字、PDF 生成和预览、报告随记录持久化。
- 全局报告与问题专题隔离、证据及输出格式校验、供应商错误处理。
- 数据、接口、隔离和报告回归测试，以及本次交付文档与配置整理。

项目开发中使用 AI 编码辅助及公开文档参考；团队与参赛信息见 README。第三方参考范围见 `open-source-references.md`。

## 验证方式

```bash
npm ci
npm test
npm run build
git log --stat
```

本次源码整理验证了 44 项自动测试和生产构建；真实 AI 调用还受到外部服务、额度与网络影响。测试供应商使用 HTTP 模拟，不把固定示例答复作为线上 AI 的替代。
