# 开发与 Git 历史说明

## 首次入库

我们在本地完成了项目早期开发，于 2026-10-28 整理比赛仓库。此前本地 `main` 分支和远程仓库均无 Git 提交，因此初始提交保存的是当天已有的源码，早期迭代没有对应的提交记录。

从首次入库起，源码、配置、文档的后续修改通过正常 Git 提交保留。评审可用 `git log --stat` 查看实际提交时间、作者和文件差异。

## 本地开发内容概览

首次入库时，项目已包含以下功能：

- 工作台、文件与自然语言导入、分类与日期汇总、基础图表。
- MiMo Agent、连续指令、工具执行反馈、多值筛选和原始明细联动。
- 账号认证、独立分析记录、保存与删除恢复。
- 语音转文字、PDF 生成和预览、报告随记录持久化。
- 全局报告与问题专题隔离、证据及输出格式校验、供应商错误处理。
- 数据、接口、隔离和报告回归测试，以及运行文档与环境配置。

我们在开发中使用了 AI 编码辅助，并参考公开技术文档。团队与参赛信息见 README。第三方参考范围见 `open-source-references.md`。

## 验证方式

```bash
npm ci
npm test
npm run build
git log --stat
```

首次入库时，44 项自动测试和生产构建均已通过。自动测试通过 HTTP 模拟模型服务；实际 AI 功能调用 MiMo，受服务状态、额度和网络影响。
